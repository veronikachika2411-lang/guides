02 / starting prompts

Build your worlds

Use these as new briefs for your own reel. Replace Lume and every display value. Review the storyboard before building the full sequence.

Claude Code / five scene briefs
1. DASHBOARD: Build a fictional waitlist dashboard in a vertical frame. Begin with a short code-like request and reveal a clean light interface: progress ring, large sign-up count, small activity cards. Use clearly fictional sample data.

2. RECORD: Build a spinning vinyl scene for a fictional music label. Put its name on the record, then make large type and the record change color on musical hits. Keep the label readable.

3. GAME: Build a short side-scrolling platform game scene. Show a character moving through obstacles with an on-screen score and combo. Make the score clearly part of the game world.

4. BRAND: Create an original identity for a fictional brand. Build one simple symbol that can rotate and resolve into a bold name card. Avoid real brand marks.

5. PAPER STORY: Build a night scene from flat paper layers: houses, trees, mountains, a winding path and a moon character. Separate the layers with light and shadows so the camera can move through them.
03 / assembly

Make the reveal count

  • Give each world a different task. The dashboard explains, the record plays, the game responds, the brand resolves, and the paper scene tells a story.
  • Keep one visual link. Reuse a small prompt bar or project mark so viewers understand that the worlds belong to one showreel.
  • Show the work together. Pull back to an editing timeline or contact sheet before the final claim. The reel uses a timeline with each scene visible.
  • Use one clear closing line. Name the worlds and the tool. Keep it readable on a phone.
  • Check every invented value. Lume and the dashboard figures are fictional. Label your own demo data honestly and remove any claim that sounds like a client result.
