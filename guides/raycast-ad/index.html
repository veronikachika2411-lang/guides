01 / what came out

One key. Every tool.

The 22.7 second wide ad begins with “How many apps did you open today?” App icons fill the depth behind the question. A shortcut brings them into one search bar.

0 to 100Question, 3D icon field, then Open / Search / Switch / Copy / Paste / Repeat.
100 to 155Option + Space, the one-key moment, and a Raycast search bar.
155 to 416Eight real features. Each card reveals its input and result in layers.
416 to 482Three phone mockups with real iOS screens.
482 to 556Extension icons fly into one panel.
556 to 680Logo ribbon, wordmark, and Raycast's slogan.

A separate vertical “desk” version places the finished ad on a monitor and an edit timeline on a laptop. It uses a photographed workspace and perspective-mapped screens. This guide describes how to build that with your own photograph.

The rule that changed the reel: use real product material. The first draft used invented interface windows and icons. The result was hard to understand.
02 / collect materials

Start with the brand

Study the official product site and press kit before asking Claude Code to animate anything.

  1. Open raycast.com/press for logos, colors, app icons and product screenshots. The press page specifies red #FF6363 and preferred dark background #151515.
  2. Open raycast.com for actual feature cards, extension examples and interface language. Save the assets you choose in your own project folder, then map each asset path in the scene data.
  3. Download Inter from its official site, or choose another font you have rights to use. Match the brand's weight and spacing. Check the license before publishing.
  4. Choose your own licensed sound effects. Make folders for impacts, whooshes, clicks and rises. Put their paths in your own audio script. Use your own desk photograph if you want the vertical version.
Nothing to download from this guide: no Raycast asset files, sound packs, SF Pro or Coolvetica font files, or desk photograph are included. Official pages can change. Recheck current brand assets and usage terms before making your version.

Keep a small asset manifest: scene, source URL, local file, crop coordinates, usage rights. For cards, crop the relevant UI from a real screenshot before rendering. A huge image in every frame slows Remotion down.

03 / ready prompt

Paste into Claude Code

Claude Code / start prompt
Make an unofficial premium concept ad for <BRAND> in Remotion,
1920 x 1080, 30 fps, with a separate vertical desk presentation.
First study the brand's official site and press kit. Make an asset
manifest with source URLs. Use only real product UI, icons and claims.
Ask me for my motion reference, licensed SFX and desk photo.
Write a frame-based scene plan before coding. Open with a question to
the viewer. Bring scattered app icons into one shortcut. Show eight
real features as cards: reveal input, then result. Use an inner camera
that follows the typing and an outer 3D camera that arcs around cards.
Then show phone screens, tools converging into one panel, and the logo.
Use CSS perspective and preserve-3d. Keep text sharp and readable.
At 120 BPM and 30 fps, a quarter-note beat is 15 frames. Place each
sound's peak on the action frame using my licensed SFX files. Leave
space for short voice lines at the beginning of scenes. No music.
Render the opening first, then the full ad. Review a frame sheet and
watch the motion and listen to the mix before calling it finished.
Label the result "Concept ad, not affiliated with <BRAND>."

Give Claude Code your chosen asset paths, frame plan and the exact crop of each real UI card. The prompt is a starting brief. It cannot reproduce my edit by itself.

Setup: Install Node.js, create a Remotion project, put your own licensed assets in its public/ folder, and paste this prompt into Claude Code in that project. Detailed setup will be in the paid guides.

const kick = KICKS.reduce((s, k) =>
  s + (g >= k ? Math.exp(-(g-k)/5) : 0), 0);
let cur = SC[0];
SC.forEach(sc => { if (g >= sc.from) cur = sc; });
<AbsoluteFill style={{transform:
  `scale(${1 + Math.min(kick,1.4)*0.024})`}}>

</AbsoluteFill>

05 / code: feature cards

Print a real card

One source image becomes three reveals. The asset is never redrawn as a fake interface.

scenes.tsx / Feature, simplified from the build
const type = p(f, tAt, tDur, eOut);
const res = p(f, tAt+tDur+1, ft.resDur ?? 8, eOut);
const layer = (key, clip) => (
  <div key={key} style={{position:'absolute',
    width:w, height:h, clipPath:clip}}>
    <Img src={ft.src} style={{position:'absolute',
      left:-cx*s, top:-cy*s, width:ft.iw*s,
      height:ft.ih*s, maxWidth:'none'}} />
  </div>
);
const layers = [
  layer('ribbon', `polygon(0 0, ${620*s}px 0,
    0 ${380*s}px)`),
  layer('input', `inset(${rt}px ${(1-type)*w}px
    ${h-re}px 0)`),
  layer('result', `inset(${re}px 0
    ${(1-res)*(h-re)}px 0)`)
];

The input reveal reduces the right inset, so it appears to type from left to right. The result rises from the lower crop. The input begins around feature frame 3; the result follows around frame 11.

scenes.tsx / two cameras
const tx = clampN(w/2-z*Tx, w-z*w, 0);
const ty = clampN(h/2-z*Ty, h-z*h, 0);
const camY = dir*lerp(-20, 9, arc);
const camZ = lerp(-380, 80, p(f,0,12,eExp));
// inner: translate(tx,ty) scale(z) inside card
// outer: perspective 2400, preserve-3d,
//        translateZ(camZ) rotateY(camY)

Clamp the inner camera so the screenshot never exposes an empty card edge. Neighboring cards sit behind it at negative Z with lower opacity.

06 / code: sound and voice

Land on the action

My make-audio2.py loads my own licensed SFX, converts them to stereo at 48 kHz and places each effect by frame. Use your own pack names and paths.

make-audio2.py / the placement idea
SR, FPS, FRAMES = 48000, 30, 680
def put(rel, frame, db, at_peak=True, end=False):
    a = load(rel)  # replace with your licensed file
    if end:
        i = int(frame/FPS*SR) - len(a)
    elif at_peak:
        i = int(frame/FPS*SR) - peak_of(a)
    else:
        i = int(frame/FPS*SR)
    a *= 10 ** (db/20)
    mix[i:i+len(a)] += a

at_peak aligns the loudest moment with the visible action. end lets a rise finish exactly on a cut. For the final mix, layer an impact, a whoosh and a click only where the picture needs them. The source mix also uses light panning, short reverb tails and loudness normalization. There is no music.

The voice was generated separately in ElevenLabs, then split by pauses and aligned to the starts of scenes. The very fast Open-to-Repeat montage stays unvoiced. Feature voice lines are one word each. Duck effects under speech and listen to the final mix; a contact sheet cannot tell you whether a voice is audible.

07 / desk and fixes

Put the ad on a desk

Use your own desk photograph. Mask the monitor, mark its four corners, and perspective-map the video into that quadrilateral. Add your own laptop screen with scene thumbnails, timeline tracks and a playhead. A softened copy of the video can cast colored light over the wall and desk. Use slow camera drift, not text shake. The vertical presentation in this project lives in Desk.tsx; its photo, mask and font files are not supplied here.

What went wrong

  • Invented product windows made the first version unclear. Use real screenshots and accurate feature names.
  • White type on Raycast red had weak contrast. Dark type on red read better.
  • White flashes on dark frames made a gray veil. Use a faint warm flash.
  • The first frame looked empty. Start some icons immediately.
  • A glowing line through the entire ad competed with the product. The final edit removed it.
  • A serif headline did not fit the rest of the design. The final ad uses Inter.
  • Long voice phrases could not keep up with short feature scenes. Use a word at the start of each scene.
  • Large PNGs slowed rendering. Crop before using them in frame-by-frame composition.
