01 · Установка15–20 минут

Ставим пять программ

Всё ставится командами в терминале. Копируй блок целиком, вставляй, жми Enter.

1Открой терминал

Windows
Нажми клавишу Win, набери PowerShell, открой.

Mac
Нажми Cmd + Пробел, набери Terminal, открой.

2Поставь Node.js, Git, Python и ffmpeg

Windows Вставляй по одной строке. На вопросы установщика отвечай Y.

PowerShell
winget install -e --id OpenJS.NodeJS.LTS
winget install -e --id Git.Git
winget install -e --id Python.Python.3.12
winget install -e --id Gyan.FFmpeg

Mac Сначала Homebrew. Это установщик программ для Mac, он попросит пароль от компьютера.

Terminal · шаг 1
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

В конце Homebrew покажет две строки под заголовком Next steps. Скопируй их из своего терминала и выполни. Потом:

Terminal · шаг 2
brew install node git python ffmpeg
Важно. После установки закрой терминал и открой заново. Иначе он не увидит новые программы.

3Поставь Claude Code

Одинаково на Windows и Mac:

Терминал
npm install -g @anthropic-ai/claude-code

Если не хочешь работать в терминале, поставь приложение Claude для компьютера с claude.ai/download. В нём есть вкладка Code, она делает то же самое.

4Проверь, что всё встало

Windows

PowerShell
node -v; python --version; ffmpeg -version; claude --version

Mac

Terminal
node -v; python3 --version; ffmpeg -version; claude --version

Каждая команда должна ответить номером версии. Если какая-то пишет «не найдено», закрой терминал, открой снова и повтори. Не помогло: поставь эту программу ещё раз.

02 · Проект10 минут

Создаём папку и запускаем Claude

1Папка и запуск

Windows

PowerShell
mkdir $HOME\showreel
cd $HOME\showreel
claude

Mac

Terminal
mkdir ~/showreel
cd ~/showreel
claude

При первом запуске Claude откроет браузер и попросит войти в аккаунт. Войди и вернись в терминал.

2Первый промпт: подготовка

Вставь это в Claude. Он сам поставит всё, что нужно для роликов, и проверит, что оно работает.

Промпт · подготовка
Подготовь в этой папке проект для моушен-роликов.

1. Поставь Remotion (React 18 + TypeScript).
2. Создай Python-окружение .venv и поставь в него numpy, scipy, soundfile, pyloudnorm.
3. Проверь, что ffmpeg доступен из терминала.
4. Сделай тестовую композицию 1080×1920, 30 fps, отрендери один кадр в PNG и покажи мне путь к файлу.

Если чего-то не хватает, установи сам и напиши, что поставил. Если что-то не получается, не останавливайся: найди причину и почини.
Про разрешения. Claude будет спрашивать разрешение на запуск команд. Это нормально: он показывает, что собирается сделать. Читай и разрешай. Когда он покажет путь к тестовому кадру, подготовка закончена.
03 · Главный промптКопируй целиком

Бриф, который делает ролик

Это шаблон моего брифа. В квадратных скобках то, что ты меняешь под себя: имя, цвета, слова на экране. Остальное можно оставить.

Промпт · бриф ролика
Собери моушен-шоурил: 20 секунд, 600 кадров, 30 fps, 1080×1920, H.264 CRF 18, yuv420p. Стиль: редакторский minimal-swiss motion design. Ролик показывает, что умеет [Claude / мой бренд].

СЕТКА (главное правило)
Темп 120 BPM. При 30 fps одна доля = 15 кадров, один такт = 60 кадров. Вся анимация и весь звук считаются от этой сетки. Каждая сцена длится ровно один такт. Каждая смена сцены происходит на первую долю такта.

ТЕХСТЕК
Remotion + React + TypeScript для видео. Python + numpy + scipy + soundfile для звука. ffmpeg для финальной склейки. Шрифты: Oswald Bold для крупных слов, Unbounded ExtraBold для логотипа, JetBrains Mono для мелкого текста.

ПАЛИТРА
Тёмный фон [#0A0A0A]. Светлый фон [#F0E8D8]. Один яркий акцент [#E8482A]. Тёмный текст [#1A1A1A]. Мелкий текст на тёмном [#8A8580]. Свечение [#FFC266].

ПОСТОЯННАЯ РАМКА НА КАЖДОМ КАДРЕ
Сверху слева "[БРЕНД] · 2026". Сверху справа таймкод. Сверху по центру четыре квадрата, активная доля подсвечена. Снизу слева номер и название сцены. Снизу по центру полоса прогресса по сценам. Сбоку вертикально "[@мой_ник]".

ГЕРОЙ
Одна оранжевая точка проходит через весь ролик: падает, прыгает по словам, рисует графики, нажимает кнопки.

СЦЕНЫ (по одному такту)
00 ТИТР. С нулевого кадра на экране текст "[ЭТОТ РОЛИК НИКТО НЕ МОНТИРОВАЛ]". Точка падает и отбивает доли. На третью и четвёртую доли врезаются слова "[CLAUDE]" и "[В ДЕЛЕ.]". Точка взрывается в оранжевый фон.
01 ТИПОГРАФИКА. Оранжевый фон. Четыре строки "[КАЖДЫЙ / КАДР / ПОПАДАЕТ / В БИТ.]", по одной на долю, у каждой свой способ появления. Строки вписаны ровно в ширину кадра.
02 КОД. Сверху редактор, код печатается блоками. Снизу по долям собирается карточка интерфейса: заголовок, цифра, график, кнопка. Точка нажимает кнопку.
03 ОБЪЁМ. Светлый фон. Слово "3D" с настоящей глубиной на чистом CSS, пол в перспективе. Ракурс меняется на каждую долю.
04 ДАННЫЕ. Радиальная диаграмма, лучи качаются на бочку. Счётчики набегают.
05 ЧАСТИЦЫ. Лучи диаграммы рассыпаются в 400 частиц. На каждую долю они собираются в новую фигуру: кольцо, спираль, буква, контур окна.
06 ПРОМПТ. Контур превращается в окно терминала. Печатается запрос, появляются шаги с галочками, счётчик кадров доходит до 600.
07 ВСЁ СРАЗУ. Быстрая нарезка всех сцен под барабанную сбивку. В конце четверть секунды чёрного экрана и тишины.
08 ПОДПИСЬ. На первую долю врезается "[CLAUDE.]", ниже "[@мой_ник]".
09 ПРИЗЫВ. Оранжевый фон. "[НАПИШИ ШОУРИЛ]", плашка комментария, в которой печатается слово, строка "[ПРИШЛЮ ПРОМПТ И ГАЙД]".

ПЕРЕХОДЫ
Все разные: взрыв точки, шторки, поворот куба, резкий вертикальный сдвиг с размытием, морфинг без склейки, белая вспышка, глитч.

ЗВУК
Синтезируй всё сам в numpy, без готовых файлов. Музыка 120 BPM, фа минор: бочка в каждую долю, клэп на вторую и четвёртую, хэты, бас, аккорды, арпеджио. Музыка проседает под бочку. В такте 07 сбивка и нарастание, перед тактом 08 полная тишина, на первую долю такта 08 мощный удар. Поверх музыки звуки на каждое событие в кадре: приземления точки, появление слов, печать, клики. Каждый звук ставь по номеру кадра.
Мастер: −14 LUFS, true peak не выше −1 dBTP, стерео 48 kHz.

ПОРЯДОК РАБОТЫ
1. Создай файлы. Проверка типов должна проходить.
2. Отрендери 30 ключевых кадров в один контакт-шит и посмотри на него сам.
3. Self-QA: пройди по каждой сцене и каждому переходу. Ищи текст, который вылезает за край или наезжает на другой текст, чёрные кадры, пропавшую рамку. Нашёл ошибку: исправь и перерендери.
4. Собери финальный mp4 со звуком.
5. Проверь по готовому файлу: длительность, число кадров, громкость, попадание бочки в сетку.
6. Одним сообщением напиши: путь к файлу, размер, громкость, что проверил и что не смог проверить.

Не останавливайся, пока не будет готового mp4 со звуком.
Сколько ждать. У меня первый прогон занял около получаса. Claude всё это время пишет, рендерит и проверяет сам. Можно отойти.
04 · СинхронПочему всё попадает в бит

Правило 15 кадров

Секрет не в таланте, а в арифметике. Выбери темп, при котором одна доля занимает целое число кадров. Тогда музыку и картинку можно считать от одной линейки.

ТемпКадров на долюХарактер
90 BPM20Спокойный, для текста и объяснений
100 BPM18Уверенный, для презентаций
120 BPM15Энергичный, для шоурила. Мой выбор
150 BPM12Очень быстрый, для нарезок

Формула при 30 кадрах в секунду: 1800 / BPM. Если получилось дробное число, темп не подходит.

Хочешь подложить готовый трек вместо синтеза? Найди трек с известным темпом из таблицы и напиши Claude: «вот файл track.mp3, темп 120 BPM, первая доля на такой-то секунде, привяжи сцены к нему».

05 · ПравкиГотовые фразы

Как менять ролик

Не объясняй, как чинить. Говори, что видишь и что хочешь.

Заменить текст
В сцене 01 замени строки на "[ТВОИ / ЧЕТЫРЕ / СЛОВА / ТУТ.]". Проверь, что они не наезжают друг на друга, и перерендери финал.
Сменить палитру
Поменяй акцентный цвет на [#2F6BFF] во всём ролике. Проверь контраст текста на акцентном фоне. Перерендери контакт-шит и покажи.
Усилить звук
Музыка звучит плоско. Сделай бочку плотнее, добавь больше верхов и сделай удар на такте 08 мощнее. Громкость мастера оставь −14 LUFS.
Когда что-то сломалось
На [6-й секунде] я вижу [чёрный экран на несколько кадров]. Найди причину, почини и проверь покадрово, что проблема ушла.

Пять багов, которые Claude нашёл сам

Ролик не получился идеальным с первой попытки. Он получился потому, что в брифе был пункт про самопроверку.

Что былоКак нашёл и что сделал
Три чёрных кадра в переходе между сценамиПроверил финальный файл покадрово. Переписал переход другим способом.
Строки наезжали друг на другаУвидел на контакт-шите. Пересчитал высоту строк.
Сумма не влезла в карточкуУвидел на контакт-шите. Уменьшил шрифт.
Точка закрыла надпись на кнопкеЗаметил, что вместо слова читается каша. Сдвинул точку.
Музыка гудела низомИзмерил спектр. Поднял аккорды и хэты.
Вывод. Самые важные строки в брифе: «посмотри на контакт-шит сам», «проверь по готовому файлу» и «напиши, что не смог проверить». Без них ты получишь ролик с багами и уверенный отчёт, что всё отлично.
07 · ВопросыКоротко

Частые вопросы

Сколько это стоит?

Нужна только подписка Claude. Node.js, Python, ffmpeg и Remotion бесплатны для личного использования. У Remotion есть платная лицензия для компаний: если делаешь ролики для бизнеса, посмотри условия на remotion.dev.

Терминал выдал красную ошибку. Что делать?

Скопируй текст ошибки и вставь Claude со словами «вот что произошло, почини». Он для этого и нужен.

Claude остановился и ждёт. Это нормально?

Да. Либо он спрашивает разрешение на команду, либо закончил этап. Прочитай последнее сообщение и ответь или напиши «продолжай до финала».

Можно другой размер или длину?

Да. Поменяй в брифе цифры. Длину считай тактами: при 120 BPM один такт занимает 2 секунды.

Получится такой же ролик, как у меня?

Похожий по структуре, но не идентичный. Claude каждый раз решает детали заново. Это плюс: у тебя будет свой.

Где лежит готовый файл?

Claude напишет путь в последнем сообщении. Обычно это папка out внутри проекта.

08 · ПубликацияЧек-лист

Перед тем как выложить

  • Посмотри ролик со звуком на телефоне. Claude музыку не слышит, он её только измеряет.
  • Важный текст не должен попадать в нижнюю четверть кадра: там описание и кнопки Instagram.
  • Первый кадр должен читаться без звука. Это и есть обложка.
  • В описании первая строка короткая, в конце одно действие: какое слово написать в комментарии.
  • Файл: mp4, 1080×1920, до 90 секунд. Этот ролик весит около 20 МБ.
