Как поставить Superpowers: плагин, который заставляет Claude Code задавать вопросы, писать план и проверять себя. Для Windows и Mac, по шагам, с командами для копирования.

00 · Что это2 мин чтения

Зачем это нужно

Ты пишешь «сделай приложение», и Claude сразу пишет код. Без вопросов и без плана, а чинить потом тебе. Superpowers меняет порядок: сначала вопросы, потом план, потом работа по шагам с проверкой.

01 · Подготовка5 минут

Что должно стоять

Нужен только Claude Code и подписка, в которую он входит.

1Открой терминал

Windows Нажми Win, набери PowerShell, открой.
Mac Нажми Cmd + Пробел, набери Terminal, открой.

2Проверь, что Claude Code установлен

Терминал
claude --version

Ответил номером версии: всё есть. Пишет «не найдено»: сначала поставь Node.js с nodejs.org, потом выполни:

Терминал
npm install -g @anthropic-ai/claude-code

3Запусти Claude Code в папке проекта

Терминал
claude

Дальше все команды вводятся уже внутри Claude Code, в строке, где ты обычно пишешь задачу.

02 · Установка1 минута

Ставим Superpowers

AИз официального каталога плагинов

Основной способ. Вставь внутри Claude Code:

Claude Code
/plugin install superpowers@claude-plugins-official

BЕсли способ A не нашёл плагин

Подключи каталог автора и поставь из него. Две команды по очереди:

Claude Code · шаг 1
/plugin marketplace add obra/superpowers-marketplace
Claude Code · шаг 2
/plugin install superpowers@superpowers-marketplace

✓Как понять, что получилось

Закрой Claude Code и открой заново, чтобы плагин подхватился. Потом напиши любую задачу на создание чего-нибудь, например:

Проверка
Давай сделаем список дел на React

Рабочая установка не начнёт писать код, а сначала спросит, что именно тебе нужно.

03 · РаботаКаждый день

Как этим пользоваться

1Просто опиши задачу

Специальных команд учить не надо. Плагин сам включается, когда видит, что ты что-то строишь.

2Отвечай на вопросы

Агент спросит, для кого это, что главное, какие ограничения. Потом покажет решение короткими частями. Читай и поправляй: это самое дешёвое место, чтобы поймать ошибку.

3Утверди план и дай старт

План состоит из мелких шагов. Когда он тебя устраивает, скажи «начинай». Выполнять можно двумя способами:

СпособЧто происходит
Через субагентовНа каждый шаг новый помощник, после каждого проверка. Самый тщательный.
В одной сессииВсе шаги подряд и одна проверка в конце. Самый дешёвый по лимиту.

4Готовые фразы

Начать с вопросов
Хочу сделать [что именно]. Сначала задай мне вопросы, код пока не пиши.
Посмотреть план
Покажи план целиком, прежде чем что-то менять.
Тщательный режим
Выполняй план через субагентов, с проверкой после каждого шага.
Если что-то пошло не так
figure out what went wrong with superpowers in this session

Последняя фраза из инструкции автора: по ней агент разбирает сессию и объясняет, где процесс сломался.

04 · ВнутриСемь шагов

Что он делает сам

ШагЧто происходит
1 · brainstormingВопросы до начала работы. Для проекта пишет документ с решением.
2 · git worktreesСоздаёт отдельную ветку и рабочую копию, проверяет, что тесты проходят.
3 · writing plansДелит работу на шаги по 2–5 минут с точными файлами и проверками.
4 · выполнениеЧерез субагентов или в одной сессии, смотри раздел 03.
5 · TDDСначала тест, который падает, потом минимальный код, потом тест проходит.
6 · code reviewСверяет сделанное с планом. Критичные замечания останавливают работу.
7 · завершениеПроверяет тесты и предлагает: слить, открыть PR, оставить или выбросить.

06 · ЧестноЧто учесть

Перед тем как ставить

  • Это дольше и дороже по лимиту. Вопросы, план, субагенты и проверки расходуют больше, чем «просто напиши код». Сколько именно, я не замеряла. Режим «в одной сессии» экономнее.
  • Он рассчитан на проект с git и тестами. Создаёт ветки и рабочие копии, а код, написанный до тестов, удаляет и пишет заново. Если ты с git не знакома, первое время это будет непривычно.
  • «Пару часов работает сам» это слова автора из описания проекта. Я такое время не проверяла.
  • Счётчик установок. По описанию автора, одна необязательная функция загружает логотип с его сайта и передаёт только номер версии плагина. Отключается переменной окружения SUPERPOWERS_DISABLE_TELEMETRY=1.
  • Проект быстро меняется. Если команда из гайда не сработала, сверь её с README. Сама я команды на чистом компьютере не запускала.
07 · ВопросыКоротко

Частые вопросы

Это бесплатно?

Да. Код открыт, лицензия MIT. Платишь только за свою подписку Claude.

Нужно уметь программировать?

Отвечать на вопросы и читать план можно без этого. Но процесс построен вокруг тестов и git, поэтому базовое понимание помогает.

Он включается на каждую мелочь?

По описанию автора, мелкие правки согласуются прямо в чате, а полный процесс с документом и планом включается для проектов.

Как обновить и удалить?

Обновления чаще всего ставятся сами. Удалить: внутри Claude Code открой /plugin и убери superpowers из списка.

Терминал выдал ошибку. Что делать?

Скопируй текст ошибки и вставь в Claude Code со словами «вот что произошло при установке superpowers, почини».
