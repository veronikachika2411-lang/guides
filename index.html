How it works

Every frame is code.

These reels were never edited. I describe each scene, Claude Code writes it, Remotion renders the MP4.

You type
# one sentence is enough to start
> make the word CLAUDE in chrome,
  the camera flies through a tunnel of cubes,
  letters fall with real physics

# then you give notes, like to an editor
> the letters pop in too hard.
  make them float in softly.
Claude Code does

From a sentence to an MP4

  1. Writes the scene in React and three.js: light, materials, camera.
  2. Times every event to the beat of the track.
  3. Checks still frames for cut-off or covered text.
  4. Renders a vertical 1080×1920 MP4, ready for Instagram.
